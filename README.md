# TRINITY BREAK — 最後のシグナル

**[ゲームを遊ぶ](https://jtcpride.github.io/trinity-break/)**

RED・BLUE・GOLDを切り替えて軌道都市ノクスの制御塔へ挑む、4区画の短編SFアクション。

PC：A/Dまたは左右矢印で移動、Spaceでジャンプ、Jで攻撃、Kで固有技、Shift/Lで加速、1/2/3で切替、RでARMAROID、Escで一時停止。
スマホ・タブレット：画面内のボタンで操作。横向きを推奨します。

REDは近接・射撃と連続ブースト、BLUEは敵機の直接操作、GOLDは加速と大型敵へのワイヤー飛翔。通常敵を回避して進むこともできます。

GitHub Pagesの公開元にこのリポジトリのdevelopmentブランチのルートを指定すると、そのまま配信できます。ビルドやサーバー処理は不要です。

このリポジトリは配信用の静的ファイルです。原画は提供された参照画像を使用し、ゲーム内描画と音は本作用に作成しています。素材・コードの利用許諾は別途明示されるまで付与しません。
